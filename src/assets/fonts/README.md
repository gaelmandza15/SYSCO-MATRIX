# Fonts

La police **Inter** (variable) est embarquée localement dans ce dossier
(`Inter.var.woff2`), ce qui garantit un rendu hors-ligne sans appel à
Google Fonts.

## Si vous devez la remplacer

1. Télécharger la police variable depuis le dépôt officiel
   `rsms/inter` (fichier `InterVariable.woff2`).
2. Le renommer en `Inter.var.woff2`.
3. Le déposer dans ce dossier.

En cas d'absence du fichier, l'interface retombe automatiquement sur une
pile de polices système (`-apple-system`, `Segoe UI`, ...).
